# Md. Aatir Usmani - Professional Portfolio Website

Personal portfolio website of **Md. Aatir Usmani**, featuring scroll-driven interactive animations, complete certification gallery, project showcases, photo gallery, and interactive file viewer modals.

## 🚀 Key Features

- **Interactive Scroll-Driven Animation**: Smooth frame-by-frame canvas animation synchronized with scrolling.
- **Certifications Showcase**: Filterable view of professional certifications with interactive preview modal for documents and images.
- **Photo & Project Gallery**: Lightbox image gallery and project case studies.
- **Responsive & Modern Design**: Dark/light theme support, glassmorphism UI, clean typography, and seamless mobile responsiveness.

## 📁 Project Structure

```text
├── assets/                  # Profile headshot and graphic portfolio assets
├── Certificates/            # Certification images and documents
├── frames/                  # 240-frame sequence for the scroll animation
├── Projects/                # Project documentation and resources
├── index.html               # Main website markup
├── style.css                # Custom CSS styling and animations
├── script.js                # Core interactive JavaScript and canvas rendering
├── README.md
└── .gitignore
```

## 💻 Getting Started Locally

Open `index.html` directly in any modern web browser or serve it using a local HTTP server:

```bash
# Using Python
python -m http.server 8080

# Using Node / npx
npx serve .
```

Then visit `http://localhost:8080` in your browser.
